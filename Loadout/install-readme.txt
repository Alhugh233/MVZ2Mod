MVZ2 Loadout v{VERSION}  ——  安装说明
============================================================

【做什么用的】

  用可视化面板替代原版调试控制台的输入窗口，便于快速做测试。
  面板分「关卡内」和「关卡外」两套，各自分页。本版本包含两个页面1：

    关卡内 · 页面1「基础」（5 行 × 4 列）
      [ ]上帝模式    [ ]无限能量     [ ]无限星之碎片 [ ]禁用冷却
      [ ]后台暂停    [ ]忽略大波事件 [ ]自动收集     [ ]隐藏HUD
      背景:<>        关卡:<>         难度:<>         音乐:<>
      旗数:__        波数:__         能量上限:__     星之碎片上限:__
      出怪点数:__    出怪倍数:__     出怪幂数:__     {重载}

    关卡外 · 页面1「进度」
      绿宝石:__            | |已解锁条目|（始终按 id 排序，✔ = 已解锁）
      {解锁全部关卡}        | 解锁条目:<>
      {解锁全部成就}        | {添加} {删除}
      {移除商店已购买项}    |

  「<>」是**带补齐的输入框**：点进去会列出候选，↑↓ 选、Tab/Enter 补全，
  也可以直接敲 id（或中文名 / 英文名，能查到的话）。

  （后续页：蓝图 / 制品 / 场地 / 实体 / 出怪 / 设置 —— 见仓库里的 Loadout.txt。）


【安装】

  1. 解压到游戏根目录（与 MinecraftVSZombies2.exe 同级）。
     压缩包已自带 BepInEx 运行环境与 **DSHCore 前置**（硬依赖，必须一起装），覆盖即可。

  2. 启动游戏，用 **debug 存档**（用户名 debug）进入游戏。
     所有功能只在原版 debug 存档下有意义（与原版控制台一致）。


【入口与按键】

  左上角蜘蛛图标   打开 / 关闭面板（原版调试图标的副本）
  /                原版控制台（**保留**，本 mod 没有动它）
  /loadout         面板状态、open / close / page / dump / report / reload

  面板里：
    - 顶部一排是**页签**，点它切页（当前页按钮置灰）
    - 按住**标题行或页签行**可以拖动面板
    - 底部「关闭」关面板
    - 进出关卡时会自动关闭面板（两套页面不混用）

  ⚠️ 默认**不注册热键**（原版 debug 模式下 F1~F7 都被官方占了）。
     想要热键就在配置里填一个 KeyCode 名（如 F5）。


【配置文件】

  BepInEx/config/qoznos.mvz2.loadout.cfg

  [Compat]
    CompatLevel = Safe / Standard / Full
      Safe     只用原版已有的属性与接口，不挂任何会改行为的补丁。
               面板照常能用，但打开时关卡不暂停、选卡列表保持原样、图标不接管。
               **和别的 mod 冲突时先降到这一档排查。**
      Standard 默认。额外：面板打开时速度=0、选卡界面显示所有实体蓝图、
               蜘蛛图标作为面板入口。
      Full     全部功能，含需要替换官方行为的危险功能（目前只有预留的传送带卡池接管）。

  [Compat.Features]
    每个功能可单独 Auto / On / Off（Auto = 跟随 CompatLevel）。

  [General]
    PanelHotkey = （留空 = 不注册热键）
    SelfTest    = （留空 = 关闭；menu / level / all 供排障，会把布局 dump 写进日志）


【已知边界】

  - 「背景 / 关卡」需要点「重载」才生效（章节决定地格布局，只在关卡初始化时建立）；
    只改背景时进度保留，换成别的关卡则没有可复用的状态存档、会从头开始。
  - 出怪三参数受原版硬上限 500 限制。
  - 关卡外页面的绿宝石 / 解锁 / 反解锁**直接写用户存档、不可撤销**；
    原版没有「按成就解锁」的入口，「解锁全部成就」= 解锁全部已注册的解锁条件。
  - 面板里**没有下拉框**：原版下拉框组件在本游戏里展开列表画不出来，
    所以一律用带补齐的输入框（这也是需求里「<>」的定义）。
  - 背景没有官方名称（原版数据里就没有），只有内置章节表，因此没有英文名可匹配。
