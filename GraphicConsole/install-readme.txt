MVZ2 图形化控制台 v{VERSION}  ——  安装说明
============================================================

【做什么用的】

  用可视化面板替代原版调试控制台的输入窗口，方便快速做测试。

  面板分「关卡内」和「关卡外」两套，各自分页：

    关卡内 · 页面1「基础」
      [ ]禁用失败   [ ]无限能量   [ ]无限星之碎片   [ ]禁用冷却
      [ ]禁用暂停   [ ]忽略大波事件 [ ]自动收集      [ ]关闭GUI(F1)
      背景:<>      关卡:<>       难度:<>          音乐:<>
      旗数:__      波数:__       能量上限:__      星之碎片上限:__
      出怪点数:__  出怪倍数:__   出怪幂数:__      {重载}

    关卡外 · 页面1「进度」
      绿宝石:__                | 已解锁条目（信息列表）
      {解锁全部关卡}             解锁条目:<>
      {解锁全部成就}             {添加} {删除}
      {移除商店已购买项}

  （后续页：蓝图 / 制品 / 场地 / 实体 / 设置 —— 见仓库里的 Loadout.txt。）


【安装】

  1. 解压到游戏根目录（与 MinecraftVSZombies2.exe 同级）。
     压缩包已自带 BepInEx 运行环境与 DSHCore 前置，直接覆盖即可。

  2. 启动游戏，用 **debug 存档**（用户名 debug）进入游戏。
     所有功能只在原版 debug 存档下有意义（与原版控制台一致）。


【按键】

  F2      打开 / 关闭图形化面板 —— 打开时关卡会暂停（与原版控制台一致）
  /       原版控制台（**保留**，没有被动过）
  F1      显示 / 隐藏关卡 HUD

  面板里：
    - 顶部一排是页签，点它切页
    - 底部「关闭」= 关面板；「原版控制台」= 关面板并打开原版控制台
    - /gc 可以在原版控制台里查看状态、重新解析 UI 素材


【配置文件】

  BepInEx/config/qoznos.mvz2.graphicconsole.cfg

  [Compat]
    CompatLevel = Safe / Standard / Full
      Safe     只用原版已有的属性与接口，不挂任何会改行为的补丁。
               面板照常能用，但打开时关卡不暂停、'/' 会叠开原版控制台、
               选卡列表保持原样。**和别的 mod 冲突时先降到这一档排查。**
      Standard 默认。额外接管控制台状态（面板打开时暂停关卡）与
               「选卡界面显示所有实体蓝图」。
      Full     全部功能，含需要替换官方行为的危险功能（如传送带卡池接管）。

  [Compat.Features]
    每个危险功能都能单独 On / Off（Auto = 跟随上面的等级）：
      ConsoleStateTakeover    接管控制台开关状态
      AllBlueprintsInChoose   选卡界面显示所有实体蓝图
      ConveyorTakeover        传送带卡池接管（尚未实现，预留）

  [General]
    PanelHotkey   面板热键（KeyCode 名，默认 F2）
    PauseLevelOnOpen  打开面板时是否暂停关卡（默认 true）


【已知边界】

  - 「背景 / 关卡」改了要点「重载」才生效（Area 决定地格布局，只能在关卡初始化时建立）。
    重载会顺带清掉本关所有面板改动 —— 等同重开一局。
  - 「出怪点数 / 倍数 / 幂数」会被原版写死的硬上限 500 顶住，调大了也超不过。
  - 「解锁全部成就」实际会解锁**全部已注册的解锁条件**（含关卡与商店）——
    原版成就是条件驱动的，没有单独的按成就解锁入口。
  - 所有解锁 / 绿宝石 / 商店操作都直接写用户存档，**不可撤销**。


【卸载】

  删掉 BepInEx/plugins/GraphicConsole.dll 即可
  （DSHCore.dll 如果别的 mod 还要用就别删）。
