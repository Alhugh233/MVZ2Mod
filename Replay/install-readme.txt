MVZ2 Replay（关卡回放录制）
============================================

适用版本：Minecraft vs Zombies 2（MVZ2） 0.7.0 test-10（x86 / IL2CPP）

【前置要求】
无需单独安装前置 —— 本包含以下全部：
  · BepInEx 6 运行环境
  · DSHCore 前置库
  · 本 mod 的插件
解压到游戏根目录即可。

【录制】
默认**不自动录制** —— 平时玩关卡不会产生任何回放文件。要录的话有两条路：
  · 主菜单 → 更多选项 → 插件 → 回放，按面板上的「录制」
  · 或者把配置里的 AutoRecord 改成 true（进关卡自动开录）
录制结束（关卡结束 / 退出关卡 / 退出游戏 / 手动停止）时写出 .mrep：
  %USERPROFILE%\AppData\LocalLow\Cuerzor\<游戏名>\userdata\user<N>\replays\
（想换位置就改 BepInEx\config\qoznos.mvz2.replay.cfg 的 OutputDir；见 README）
注意：落盘只在录制**结束**时发生一次，关卡中途不会自己冒出文件。
想中途也落盘（防崩溃丢档）就把 [General] AutoSave 改成 true（默认关）。

【播放】
主菜单 → 更多选项 → 插件 → 回放（入口就在「资源包」下面那一行）
  · 面板第一行是回放数量，右边一排按钮：导入 / 按时间 / 按关卡 / 按时长
  · 「导入」会弹系统的「打开文件」对话框，选一个 .mrep 就能收进回放列表
    （同名已存在时自动改名成 xxx (2)，不会覆盖你原有的那一条）
  · 列表每一行是「关卡名 · 存档时间 · 时长」，右边是 [播放] [删除]
  · 「删除」会再弹一个面板二次确认
  · 最多保留 50 个（改配置的 MaxReplays；超出后每写出一份就清一次最旧的）

游戏内控制台指令（默认关闭）：
  在配置里把 [General] Commands 改成 true 之后可用：
  /replay rec [名字]   开始录制
  /replay stop         结束录制并写出文件
  /replay play <名字>  播放回放
  /replay playlast     播放最近写出的那一条
  /replay stopplay     中止播放
  /replay list         列出所有回放
  /replay status       查看状态
  /replay dir          查看输出目录

【回放一致性】
每 150 个逻辑 tick 会记一条「状态指纹」（能量 / 波次 / 旗数 + 实体清单哈希 +
7 条 RNG 流各自的哈希；间隔由配置的 FingerprintInterval 控制）。播放时会逐条重算并与
录制时比对，不一致会写进控制台小结，
能直接指出「从哪个 tick 起、是哪一类实体 / 哪一条 RNG 流先跑偏」。

【播放时的假鼠标】
回放里只有离散的动作、没有鼠标轨迹，所以 mod 会把它插值成一条连续轨迹，
并额外画一个「游戏光标样式」的假鼠标（什么都没拿的时候游戏本来不画指针）。
同时游戏原生的硬件光标照旧跟着你自己的鼠标走 —— 画出来的那个是回放的假鼠标，
你自己屏幕上那个是真鼠标，两者一眼能分开。
不想要就设 FakeMouse = false（另有 FakeMouseTicks / FakeMouseEase / FakeMouseScale / FakeMouseGameCursor）。

【回放结束面板】
一次播放结束（播完 / 关卡通关 / 关卡失败）时会弹一个面板，三个按钮：
  · 导出 .mrep —— 弹系统的「另存为」对话框，把这一条回放（连同 .mrep.json）
    存到你挑的位置
  · 重新播放   —— 从头再播一遍
  · 退出       —— 结束播放，回到回放列表页
面板开着的时候其它输入会被拦住，免得顺手点到关卡里的东西。

【回放里的 Esc 菜单】
回放期间按 Esc 出来的还是游戏原版那个选项菜单，但有两个按钮换成了回放专用的：
  · 「重新开始」→「重新播放」（会先问一句「确认要重新播放吗？当前进度会从头开始。」，
    确认后从头再播一遍）
  · 「返回地图」→「结束播放」（会先问一句「确认要结束播放吗？结束后会弹出回放结束面板，
    可以导出、重播或退出。」，确认后**关掉菜单并弹出回放结束面板**，而不是回地图）
另外：回放重演到通关 / 失败时，原版那套「删关卡存档 + 解锁关卡 + 写难度记录」的流程
会被拦住 —— 看个回放不会改你的存档。

【注意】
回放依赖「起始关键帧 + 之后逐 tick 重演输入」。若游戏本体更新导致关卡逻辑变化，
旧回放可能复现不出同样的过程（指纹比对会报出来）。
